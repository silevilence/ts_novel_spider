# 单用户跨设备续读评估

状态：方案评估完成，尚未实现章内位置跨设备同步。范围仅为手机、电脑访问同一个本系统服务；不增加多用户体系，也不对接静读天下等外部阅读器的位置回传。

## 已有能力

- SQLite 已保存当前章节和历史最远章节。主动回读更新当前章节，最远进度不倒退；“继续阅读”使用当前章节。
- 浏览器按书籍、章节、原文/译文/双语模式在 localStorage 保存章内段落编号、段内比例和内容指纹。刷新、排版或窗口变化时恢复该段落；正文变化时回到章首并提示。
- 同一服务可提供共享的章节记录，但尚无多端并发控制；章内位置仍局限于当前浏览器，不能宣称已完成跨设备续读。

## 建议行为

以服务端版本号控制写入，保留单用户身份。每书记录最新阅读会话及各模式位置；请求带会话 ID、递增序号、已读服务端版本号、章节 ID、段落编号、段内比例、内容指纹。服务端生成时间，不能用设备时间比较先后。

| 场景 | 建议规则 |
| --- | --- |
| 手机打开电脑读过的书 | 展示“继续上次阅读”，显示章节和更新时间，确认后采用服务端位置；不让刚打开的页面立即覆盖记录。 |
| 两端同时阅读 | 新设备明确继续后成为当前会话；旧会话继续本地保存，但不得覆盖最新共享位置。旧端如要接管，需明确选择“以本机位置继续”。 |
| 主动回读 | 允许最新位置倒退；历史最远章节只增不减，不能以最高章节替代当前位置。 |
| 旧页面迟到保存 | 服务端校验会话、序号和版本；不匹配返回冲突及最新位置，不自动重试覆盖。 |
| 离线再联网 | 保留本地待同步位置；无服务端变化时条件写入，有变化时展示两个位置供选择。首次方案不承诺离线下载整书。 |
| 正文被编辑、重译或删除 | 指纹变化时保留章节并退到章首，提示失效；章节被删时回到书籍详情选择章节，不猜测相邻内容。 |
| 原文/译文/双语切换 | 分模式保存位置，禁止按比例跨不同文本映射；该模式没有位置则从章首开始。 |
| 隐藏、回收站、永久清理 | OPDS 可见性不影响系统内续读；回收站冻结位置，恢复后可用；永久清理一并删除位置。 |

正常阅读节流保存（例如 3 秒），切章和页面隐藏时补保存；关闭浏览器的最后一次发送不能保证成功，需明示可能回退几个段落。位置是导航信息，不包含正文。继续沿用服务现有访问边界，不把新增同步接口当成身份认证。

## 拆分与成本

1. 服务端位置表、迁移、条件读写和冲突测试：2–3 人天。
2. 前端位置缓存、会话接管提示、联网恢复、阅读器接入：2–3 人天。
3. 手机/电脑集中验收、重启和迁移回归、使用说明：1–2 人天。

合计约 5–8 人天；估算不含外部阅读器、账号登录、局域网自动发现或完整离线阅读。用户确认方案后再追加开发任务，本轮不实施这些新增能力。

## 两设备验收清单

- A 阅读到第 5 章中段，B 继续后定位到同一段落；不同宽度、字号和图片加载不改变段落。
- A 仍打开时 B 接管；A 迟到请求不能覆盖 B，A 显式接管后才可成为最新会话。
- B 回读第 2 章，A 继续到第 2 章；最远进度仍是第 5 章。
- A 离线阅读、B 在线前进、A 重连，出现两个位置的选择且没有静默覆盖。
- 服务重启、设备时钟不同、重复请求和乱序请求，版本与序号规则保持有效。
- 正文修改、译文变化、章节删除、回收站恢复、原文与双语切换，按上表回退并提示。
- 原件经 OPDS 下载到静读天下后，系统不显示不存在的外部阅读进度。

尚需实测的限制：移动端后台事件可靠性、长书段落定位精度、离线冲突提示的操作负担。外部阅读器支持什么同步协议，需要另行调查和确认，不能由 OPDS 下载能力推断。
