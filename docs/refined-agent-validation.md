# 精翻 Agent 模式：运行时选型与验收

日期：2026-10-27。对应 ROADMAP 中全部「精翻 Agent 模式」任务。本记录是正式接入结论；此前 Pi 文档保留为实验记录。

UI 验收更正：用户指出原交付截图存在导航截断和按钮遮挡，原“小屏表单与操作可用”判断不足。已按 [UI / UX 复查记录](refined-ui-ux-review.md) 修复并重新验证；下方旧测试数字和截图描述保留为当时的工程记录，不代表全站 UX 已通过。

## 选型结论

采用 **AI SDK 6.0.177 + 项目内持久化单主控运行时**，根 package.json 固定精确版本，package-lock.json 锁定传递依赖。Pi 1.4.0 留在 scripts/experiments/pi-sdk，不进入生产依赖，也不 fork Pi 核心。

| 方案 | 已验证能力 | 生产接入成本与结论 |
| --- | --- | --- |
| Pi 会话 SDK 1.4.0 | 工具、技能、压缩、指令插入、取消、文件恢复；真实进程退出 | Node >=22.19 与主项目 >=20 不一致，需要新的模型适配及会话文件/SQLite 一致性层。其会话恢复不能替代业务事务。保留实验，不采用。 |
| Pi Agent Core 1.4.0 | 已作为 SDK 依赖安装；未单独实现生产集成 | 技能和长期会话仍需自行组合，新增适配成本没有解决业务一致性问题。不采用。 |
| AI SDK 6.0.177 | 项目已有模型工厂、专用翻译模板、上下文预算；本轮实际协议模拟闭环 | 自建范围限定为会话编排、技能快照、指令队列、预算及事务收据；复用既有领域服务和提供商配置。采用。 |

保留根 engines.node >=20，不为 Pi 提高最低版本。生产继续使用 Dockerfile 的 Node 22；本轮 Windows 为 Node 24.15.0。没有重新验证所有 Node 20 小版本，安装仍受 lockfile 依赖 engines 约束。升级 AI SDK 时单独更新精确版本与 lockfile，并重跑本文件的协议、故障、领域回归和容器验收；不能只用安装成功作为升级依据。

第一版仅单主控、精翻领域工具、任务技能及内置参考文本。无宿主机文件工具、任意脚本、第三方技能自动发现或安装、多 Agent、创建后切换模式。真实提供商兼容性不由本地模拟证明。

## 使用方式与界面

1. 在精翻工作区新建任务，选择「Agent 自主执行」，填写目标、普通对话主控模型及执行模型，检查技能、允许操作与预算。固定流程仍为默认选项。
2. 创建只保存任务；进入后查看配置，再「开始执行」。翻译、审核、修订在授权范围内自动保存，关闭网页不影响任务。
3. 默认不允许自动确认术语。候选在术语表人工确认后继续；有明确需要时可启用该权限。Agent 维护工具只能改待确认候选，不能覆盖已确认译名或已排除决定。
4. 追加指令显示已接收/已生效，在当前工具结束后的下一次主控请求交付。暂停会取消在途请求并等待结算；停稳前不能同步原文或改配置。取消保留已保存成果。
5. 监控面板展示真实段落进度、计划、未满足条件、用量、工具收据与前后文本、审核证据和产物。历史工具记录分页；固定流程保留阶段图。
6. 人工拒绝审核意见必须填写原因；人工审核/豁免单独记录且绑定当前材料，不清除缺译或未处理意见。修改材料后需重新审核。

界面沿用 Mantine 暖纸暗色主题，配置按目标/模型/预算/高级权限/技能分组，小屏单列、桌面自适应列数；任务卡支持键盘，状态不仅依赖颜色，运行中的不可用操作禁用。创建与保存使用共享 schema，异步详情带请求版本防止迟到响应打开旧任务。

## 数据与执行边界

- 任务表新增 execution_mode，旧任务显式迁移为 workflow。refined_agent_sessions 保存唯一会话、配置、技能、计划、指令、上下文、收据、审核指纹、卷名和产物；refined_agent_defaults 保存未来任务的技能模板。
- 创建任务和 Agent 状态在同一 SQLite 事务内提交。每次启动保存配置版本快照；全局技能修改不改变既有任务，继续使用任务当前快照。
- 原文、译文、术语、审核及定稿仍以业务表为准。分页材料接口在后端绑定任务与章节范围，不维护第二套译文文件。章节范围内正文操作可用，元数据及术语是任务共享材料，界面明确说明。
- 模型只选择领域工具；工具 schema、权限、状态、章节范围、预算和完成条件由后端验证。原文与参考资料不授予权限。
- 领域服务先在内存 SQLite 草稿中执行；写回前核对业务材料指纹和模型配置。业务写入与成功收据同事务提交，任一步失败整体回滚。使用相同 operationId 重试成功操作返回原收据，不重复写入或计数；不同参数复用 ID 被拒绝。
- 服务重启将运行中收据标为 interrupted 并暂停，不自行重放不确定操作。当前协议下未提交草稿不存在业务副作用；已提交成果与成功收据同时存在。导出文件由既有引擎以确定名称覆盖，同一任务不新增重复业务记录。
- 原文同步和删除检查在途运行；人工修改使草稿失效，迟到结果无法覆盖。正常服务关闭先取消 Agent，再等待退出后释放自有数据库。

## 工具与完成条件

读取材料、按需读取技能/参考、保存计划、等待用户、请求完成和统一 execute 工具分离。execute 支持按章提取术语、维护候选、术语翻译/确认、元数据/卷章标题/正文翻译、遗漏检查、审核、关联修订与既有定稿、EPUB/Markdown/TXT 导出。操作复用 RefinedTranslationService/refined-revision，不复制状态机。

长章节术语提取遍历全部 18,000 字符窗口，再按实际模型预算拆分。专用 Index 和 HY-MT2 使用单轮 user 翻译模板，不能作为主控或结构化审核模型；Index 关闭思考。修订只改关联段落、保留硬约束，并复用逐段次数/复审/定稿/重开规则。

完成检查由实际材料决定：作品元数据、标签、卷章标题、段落完整性、失败/缺译、待确认/缺译术语、当前版本审核证据和未解决意见。审核证据绑定语言、原文、译文、章节标题、术语和定稿状态；不合法或无法唯一定位的审核响应不产生通过证据。接受意见或生成修订不等于完成；须复审，或有明确原因的人工处理。直接定稿不伪装为独立审核通过。模型一句「完成」只会进入等待状态。

## 长会话、预算和恢复

- 目标、所有追加指令、技能内容与版本、权限、预算、计划、实际待办保存在数据库，每次主控请求重新装配。最近完整工具交流保留，超出窗口或上下文预算时成对移除旧交流；不会用模型摘要代替硬约束，也不宣称无损保留全部对话。
- 资料及工具定义计入模型预算。必要材料过大时暂停并说明原因，不能静默截掉约束；历史工具收据仍可查询。
- 主控与执行模型共用调用预算；每次真实尝试预先计数，关闭 SDK 隐式重试，领域的显式重试各计一次。用量缺失单列 unknownUsage，不当作零成本。修订预算按领域修订操作计数，段落次数另外沿用原规则。
- 累计运行时间、调用量、修订量重启不清零。崩溃恢复保守计入最后记录到重启间的时间（可能包含停机时间）；用户可提高预算。无进展次数在人工继续时重置，累计调用不重置。
- 重复成功 ID、无物料进展操作和纯读取循环触发暂停；局部失败返回原因，其他章节仍可继续；达到全局预算停止后续请求。日志与收据错误脱敏。

预览程序使用内存 SQLite、独立临时目录和本地 OpenAI 协议模拟服务，不读取用户运行数据或调用真实模型。生产 Dockerfile 使用 Podman 验证，非 Docker Engine/Compose 本身的验证；未挂载宿主机业务数据。容器网络首次重建 Debian apt 连接超时，重试沿用已验证构建层；网络故障不通过更改生产基础设施规避。

## 已知边界

真实 LLM 的工具可靠性、长篇文学质量和各提供商思考参数仍需使用者的模型配置验证；本轮只使用模拟模型。没有把真实模型质量列为实现完成的证据。生产主控使用既有模型工厂，已验证 OpenAI 兼容协议；Anthropic、Google、Ollama 的真实服务本轮未调用。

草稿隔离目前按任务复制到内存 SQLite，超大任务有内存与复制成本；材料读取已分页，尚未进行整本超长小说容量压测。技能正文/硬约束过大时会明确超预算；单条参考文本上限 20,000 字符。导出文件与 SQLite 无跨存储事务：崩溃可能留下尚未登记的同名产物，重试可重建，不影响译文/修订/收据一致性。
