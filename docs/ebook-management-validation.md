# OPDS 搜索与电子书管理验收

## 范围与执行顺序

依据 ROADMAP 2026-11-13 规划，先实现 OPDS 查询与协议，再实现主动导入、管理、阅读和导出。各任务使用本地夹具执行定向测试；完整测试、构建及界面检查集中执行。安卓静读天下是目标阅读器，版本待实机记录；尚未完成安卓实测，不能据协议测试宣称兼容。

## OPDS 使用

- 静读天下优先添加后端地址下的 `/opds/v1.opds`，其他支持 OPDS 2.0 的客户端可使用 `/opds/v2`。开发时应连接后端端口，不能使用仅代理 `/api` 的 Vite 地址。
- 搜索框输入普通文字匹配书名、作者、标签、别名和简介；也可输入 `author:夏目 + tag:奇幻` 等书库组合语法。
- “按作者”“按标签”目录支持无需输入语法的分类浏览。标签目录精确匹配完整标签，`tag:` 关键词匹配可以得到包含该文字的标签。
- 支持分页及书名、最近更新排序；查询结果仅含已上架且未删除的书籍，下载链接仅对应实际存在的文件。
- 搜索发现分别使用 OpenSearch 描述文档和 OPDS 2 URI 模板，不需要安装搜索引擎服务。
