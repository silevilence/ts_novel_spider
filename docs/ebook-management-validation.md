## OPDS 使用

- 静读天下优先添加后端地址下的 `/opds/v1.opds`，其他支持 OPDS 2.0 的客户端可使用 `/opds/v2`。开发时应连接后端端口，不能使用仅代理 `/api` 的 Vite 地址。
- 搜索框输入普通文字匹配书名、作者、标签、别名和简介；也可输入 `author:夏目 + tag:奇幻` 等书库组合语法。
- “按作者”“按标签”目录支持无需输入语法的分类浏览。标签目录精确匹配完整标签，`tag:` 关键词匹配可以得到包含该文字的标签。
- 支持分页及书名、最近更新排序；查询结果仅含已上架且未删除的书籍，下载链接仅对应实际存在的文件。
- 搜索发现分别使用 OpenSearch 描述文档和 OPDS 2 URI 模板，不需要安装搜索引擎服务。

## 使用与限制

1. 在书库点击「导入电子书」，选择一个或多个文件。上传完成后解析在后端继续；待确认不等于已入库。
2. 在预览中检查正文、书名、作者、简介和标签，确认后入库。TXT 自动尝试 UTF-8，再尝试 GB18030，也可在预览切换编码。无法解析的文件独立保留失败原因，可单独重试。
3. 相同字节的文件只保留一条导入记录；改名重新上传仍识别为重复。同名不同内容可分别入库。重复文件如已在回收站，使用恢复入口；不能通过重复上传绕过删除状态。
4. 详情页支持基本信息编辑、章节维护、书签和阅读。导入书籍不支持远端抓取或定时更新。当前章节与历史最远章节分别保存；章内位置留在当前浏览器，清除浏览器数据会丢失章内位置。
5. 「下载原始文件」返回上传时字节；「选择导出格式」按当前信息和正文重新生成。EPUB 和 Markdown ZIP 包含可用的本地图片，TXT 不保留图片和富排版。生成失败保留此前有效产物。
6. 导入书籍默认不上架；开启 OPDS 分发后，原件和生成版分别提供入口。生成版沿用现有编译调度，修改元数据、章节、顺序或还原历史后重新编译，原件保持不变。
7. 删除进入回收站；恢复保留原件和阅读数据。15 天后才能永久清理，清理失败会记录具体路径并允许重试；进入清理状态后不允许恢复部分缺失的书籍。

格式边界：单个上传文件不超过 32 MB；EPUB 最多 5000 个 ZIP 条目，单条目解压后不超过 16 MB，总解压体积不超过 128 MB。支持文字为主的 EPUB 2/3，按 spine 阅读顺序转换，支持基本标题、段落、强调、列表、表格和可定位的内部链接。本轮不支持 DRM、固定版式、PDF、漫画或完整 CSS 还原。图片支持包内 PNG/JPEG/GIF/WebP；SVG、缺失图片和外部图片会提示，外部图片不自动联网下载。封面不单独管理；原件中的封面随原文件保留。
